# Celebal

Python learning exercises and practice programs completed as part of the Celebal fellowship. The repository is organized by learning day, with each day containing topic-focused scripts and exercises.

## Learning Materials

| Folder | Topics |
| --- | --- |
| [Day 1](Day-1/README.md) | Python foundations, input and output, calculations, functions, validation, recursion, modules, dates and times, randomness, and statistics. |
| [Day 2](Day-2/README.md) | Randomized data, performance measurement, retail invoicing, string processing, and regular expressions. |

The [Day 1 guide](Day-1/README.md) and [Day 2 guide](Day-2/README.md) list their lesson folders and programs, explain what each exercise practices, and suggest an order for working through the material.

## Getting Started

- Install Python 3.9 or newer.
- Clone or download this repository and open it in a terminal or editor.
- Run a program from the repository root. For example, in PowerShell:

```powershell
python Day-1/day01-python-best-practices/hello_world.py
```

Most exercises use Python's standard library. NumPy is required only for the NumPy statistics exercises in Day 1; install it with `python -m pip install numpy` if you plan to run those programs.
